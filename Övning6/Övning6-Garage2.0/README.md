# Övning 6 - Garage 2.0  

Samma uppgift som Övning 5 - Garage 1.0 fast med listor.  
I övrigt fokus på att bryta ut duplicerad kod i services.  
Designen lämnar mycket att önska, SoC skulle behöva förbättras genom bl.a. förflyttning av all out till menyerna (våra views) och flytta logiken till modellerna. Det har redan gjorts en hel del men det är lite spaghetti över det hela.  
Tveksam practice med att kasta exceptions för navigation, åtminstone för bakåt-navigationen.
