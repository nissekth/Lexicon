# Databasmodul - Övningar

Innehåller svar på instud.frågor och screenshots på lösningar för övningarna från föreläsningarna under dag två av databasmodulen.  
  
Övningarna är separerade av mappar namgivna efter den numerering som gavs på föreläsningen, därav att det är 2, 3, 5 och 6.  
  
**N.B. Jag sitter på Linux och använder inte SSMS GUI:t utan jag använder motsvarande CLI (sqlcmd). Fortfarande Microsoft SQL Server Developer edition och T-SQL men via terminalen istället.**
